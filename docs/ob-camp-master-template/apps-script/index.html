本人確認

初回登録時に編集用パスワードを設定します。登録内容を変更するときは、 同じ氏名とパスワードを入力して「登録内容を読み込む」を押してください。

宿泊

その日の夜に泊まる場合に「宿泊」を選んでください。夕食はその夜、朝食は翌朝に自動で付きます。 自動設定のあと、朝食・夕食は個別に外せます。

リフト券

現役が指定したスキー場について、リフト券の購入を現役へ依頼する日だけ選んでください。 1日につき指定されるスキー場は1か所だけです。
