# skiheil-task

SKIHEIL（スキー部）の運営ツールを管理するリポジトリ。

Google Drive / Google スプレッドシート上で運用しているツールの **仕様バックアップ** と、
新規に開発するツールのソースコードを置く。

## 収録物

| パス | 内容 |
| --- | --- |
| [`docs/ob-camp-template/`](docs/ob-camp-template/) | 「SKIHEIL OB合宿管理（年次テンプレート）」スプレッドシートの仕様書とシート構成スナップショット |

## このリポジトリは public です

GitHub 上で誰でも閲覧できる設定になっている。そのため以下は**絶対にコミットしない**。

- 参加者の氏名・連絡先・金額などの個人情報
- パスワード、パスワードハッシュ、ソルト
- デプロイ済み Web アプリの URL（`https://script.google.com/macros/s/.../exec`）
- スプレッドシートの ID（`1AbCdEfGhIjK...` のような 44 文字前後の文字列）

バックアップ対象にこれらが含まれる場合は、リポジトリを private に切り替えるか、
該当箇所を伏せ字にしたうえで収録すること。
